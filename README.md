**Richard Henrique** — Desenvolvedor Full-Stack Júnior, com foco em construir aplicações web funcionais e bem estruturadas, do front-end ao banco de dados, utilizando JavaScript, TypeScript, React, PHP e MySQL.

Sou Jovem Aprendiz de programação web no SENAI e curso Análise e Desenvolvimento de Sistemas. Tenho interesse em produtos digitais que conectam tecnologia ao contexto real do usuário e gosto de pensar na solução como um todo: da estrutura do layout à organização do estado, da modelagem dos dados à arquitetura que sustenta o sistema.

Desenvolvi projetos como o HidroControl, uma aplicação full-stack que integra back-end com arquitetura de software, banco de dados e front-end, além de interfaces de gerenciamento de filas médicas, painéis administrativos em React, listas de tarefas com persistência local e páginas responsivas com foco em semântica e acessibilidade. Nos projetos mais focados no front-end, utilizei recursos do navegador como LocalStorage e IndexedDB para simular comportamentos que, em aplicações reais, seriam responsabilidade de um back-end.

Valorizo código limpo, componentes bem organizados, testes e uma boa experiência de uso. Estou aprendendo arquitetura de software, aprofundando meus estudos em back-end e bancos de dados (PHP, MySQL e Node.js) e explorando o Supabase como plataforma de back-end e banco de dados em nuvem.
